# Line 720

Jogo de estudo para a **Claude Certified Developer – Foundations (CCDV-F)**.
Projeto independente, sem vínculo com a Anthropic. As questões são autorais.

- **Jogar:** abra `index.html` no navegador (não precisa de internet).
- **Mudou algum `.md` de `content/` ou algo em `src/`?** Rode `node build.mjs`.

| Quero mudar... | Arquivo |
|---|---|
| Questões e briefings | `content/dominios/*.md` |
| Questões e briefings em inglês | `content/dominios-en/*.md` |
| Cenários longos do simulado (pt/en) | `content/simulado/*.md`, `content/simulado-en/*.md` |
| Textos da interface (pt/en) | `content/idiomas.md` |
| Pesos da prova, tempo, nº de questões | `content/prova.md` |
| Dificuldade, XP, custos, poderes | `content/balanceamento.md` |
| Regras e telas | `src/jogo.js` |
| Animações, sons, trens | `src/visual.js` |
| Mapa do metrô | `src/metro.js` |
| Chama, nível, missões | `src/painel.js` |
| Cores e layout | `src/estilo.css` |

Formato das questões: `docs/COMO-EDITAR.md`. Regras: `docs/DESIGN.md`. Fontes: `docs/CERTIFICACAO.md`. Próximos passos: `docs/ROADMAP.md`.
